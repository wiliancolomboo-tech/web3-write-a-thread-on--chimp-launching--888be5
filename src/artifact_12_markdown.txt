[Tweet 2: The Problem with Legacy NFTs]
Under legacy Token Metadata (Token-2022 / SPL-Token), every single NFT required 3 distinct accounts:
1. Mint Account
2. Associated Token Account (ATA)
3. Metadata & Master Edition Account

Cost? ~0.022 SOL in rent-exemption per mint.
At 10,000 items, that is ~220 SOL locked up purely in state rent.

---

[Tweet 3: Metaplex Core's 1-Account Revolution]
Metaplex Core (@metaplex) eliminates account bloat.

Instead of 3 accounts, Core assets reside in ONE single account (`Core11111111111111111111111111111111111111`).
- Dynamic byte allocation
- Rent drops to ~0.0029 SOL (~85% cost reduction)
- Clean, indexable state directly mapped to owner Pubkeys.

$CHIMP passes every fraction of those gas savings back to the community.

[Tweet 4: Compute Budget Optimization]
Legacy NFT mints: 120,000 - 180,000 CU.
Metaplex Core mints: ~35,000 CU.

By minimizing compute footprint:
1. Mint transactions land in 1 block (zero dropped txs during high-congestion periods).
2. Priority fee spikes have zero impact on $CHIMP minters.
3. Batch transactions can pack up to 4 Core mints in a single Solana tx.
